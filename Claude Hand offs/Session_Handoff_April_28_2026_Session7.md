### Key Findings

**1. The Gemini adventure engine is pre-Narrative Engine design work.** Created late February 2026, before the 21-document Narrative Engine spec was built. Many concepts were subsequently codified with greater rigor in the Operating Philosophy. The Gemini chat hit its capability ceiling on several systems that needed more complexity than it could sustain.

**2. Unique content worth preserving from the Gemini chat:**
- **10-node session architecture** — canonical per Alex, needs integration with Doc 4C
- **5-point combat ecology** (Kanon/Anima/Unified/Bleed/Mundane) — salvageable but needs expansion to college-derived model
- **"Cosmic Friction Pool"** — antagonistic mechanic linking FP spends to Selûnæ-targeted consequences
- **Mission shell metadata tags** — Arc_Placement, Focus, Reality_State, Employer_Type, Monster_Type, Global_Modifier
- **Tile-set grammar** — Infiltration → Transit → Choke Point → Objective → Extraction with weighted environmental blending (60/30/10)
- **XP yield baseline** — ~9-10 XP per session, difficulty on a 1-5 relative scale vs. Mastery
- **Tick economy** — 1 tick = 6 seconds = 1 combat round; 1 encounter ≈ 100 ticks

**3. The adventure generation toolkit is a complete five-layer system:**
- Layer 1 — Mission Shell (metadata tags from engine chat)
- Layer 2 — Objectives (Ultimate list, 120 objectives across 16 categories)
- Layer 3 — Twists (V4 Masterlist, ~150 complications across 24 categories)
- Layer 4 — Constraints (Expanded doc, ~40 high-concept operational modifiers)
- Layer 5 — Session Architecture (10-node pacing skeleton, XP yield, tick economy, Cosmic Friction Pool)

Layers 1-4 feed into Docs 5A/5B (Seed Management and Oracle Tables). Layer 5 is the concrete implementation of Doc 4C (Beat Analysis).

**4. The Society Generator complements the Political Alloy system.** The Alloys provide the combinatorial vocabulary (9,600 combinations). The Society Generator provides the profiling methodology using a four-pillar radar chart mapped through the Psyche Schema. Not in conflict — they're two interfaces to the same political architecture.

**5. The character profile in the Gemini chat has extensive legacy issues.** Wrong HP formula, wrong skill name (Insight not Instinct), wrong social HP pool name (Reputation not Poise), 2d10 instead of d20, expanded effects list beyond canonical 23+Variable, Influence as background instead of Clout. All expected — the profile predates current canonical decisions.

**6. Psyche Schema redesign mandate identified.** Analysis of the "69 questions" revealed that the v2 guide's 24-question instrument leaves significant gaps when administered cold. The Schema's dimensional architecture is sound (proven through extensive NPC/figure profiling), but the questionnaire needs a ground-up rebuild to function as a complete character creation tool. This is a UX/instrument design problem, not an architecture problem. Separate brief produced. Blocked on Batch 11.
