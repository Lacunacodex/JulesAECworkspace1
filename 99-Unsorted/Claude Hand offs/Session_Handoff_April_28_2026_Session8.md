### Key Findings

**1. Document genealogy is now clear.** The talent archive has a four-generation lineage:
- **Gen 0:** AE Stamina wip part 5 (Oct 2025, 1.5MB) — raw Gemini extraction from PF1e/3.5e sources
- **Gen 1:** Chapter 4 Combined + Complete Talent System Reference + various WIP parts (Jan 2026) — intermediate consolidations
- **Gen 2:** Inventory v2 + Missing Talents v22 + Martial Talents Final Archive (Jan-Feb 2026) — catalogued and gap-analyzed
- **Gen 3:** Talents copy doc (Mar 2026, 168KB) — comprehensive archetype reference with full mechanics + AC Unified Architecture Docs 4a-4e (Apr 2026) — Spell Sentence-decomposed transmission framework

**Gen 3 is canonical.** The Talents copy doc and AC UA Docs 4a-4e represent the current state. Everything earlier is archival source material.

**2. The talent system has two architectural layers that need reconciliation.**
- **Layer A: Archetype-organized** (Talents copy doc) — talents grouped by character role (Knight, Commando, Investigator, Rogue, etc.) with internal tree structures
- **Layer B: Transmission-organized** (AC UA Docs 4a-4e) — talents decomposed through the Spell Sentence grammar as transmission parameter unlocks

These are complementary, not contradictory. Layer A is the player-facing organization ("I am playing a Knight, what can I buy?"). Layer B is the design-level grammar ("What does this talent actually do in terms of Effects, Isotopes, and Construction Pool access?"). Both must exist simultaneously. The Talents copy doc has not been Spell Sentence-decomposed; the AC UA has not been organized by archetype. Integration is required.

**3. Talent count across documents:**

|---|---|---|---|---|
| Inventory v2 | 400+ | 185 | 175+ | — |
| Missing Talents v22 | 350+ | ~60 detailed | ~290 listed | ~80 explicitly sidelined |

| Talents copy doc | ~274 descriptions | ~274 with mechanics | — | — |
| AC UA Docs 4a-4e | 23 trees + general | Spell Sentence decompositions | 13 unresolved flags | — |

The count is inflated by duplication across documents. A unique-talent deduplication pass would likely yield **250-300 distinct talents** across all sources, of which **~200 have usable mechanics** and **~100 are framework-only or sidelined**.

**4. The 18 Ætherforged Precepts are documented in three places:**
- Talents copy doc (archetype-organized, line 7435+)
- AC Unified Architecture Doc 4a (Spell Sentence decomposition)
- AE Stamina wip part 2 (raw source — referenced as a Gen 0 consolidation source)

Only 4 of the 18 Precepts have been fully extracted as collegiate combat styles in the AC UA. The remaining 14 were flagged as outstanding in Session 5 (Gap #18: "14 of 18 collegiate combat styles unextracted").

**5. Key sidelined concepts needing core system resolution before they can be mechanized:**
- Combat Maneuvers (Grapple, Trip, Disarm, Shove) — core resolution mechanics undefined
- Rage Mechanic — foundational "Rage" state rules undefined
- Critical Hit Specialization — needs "Degrees of Success" integration (five-degree system exists but combat SWF cost is OD-8)
- Precision Damage — needs "Sneak Attack" core talent (Anatomical Strike exists as Crux)
- Weapon Focus / Weapon Specialization — sidelined for redesign as single scaling talent

**6. The Talents copy doc uses mostly correct ÆC terminology** but retains legacy terms in places: "Agility" (should be Finesse), "Charisma" (should be Presence), "BAB" references, "AC" (should be Composite Defense), "Wisdom" (should be Wits). A terminology pass is needed but the document is structurally sound.

**7. The Talents copy doc contains unique structural content not found elsewhere:**

- Thematic Defense assignments per archetype
