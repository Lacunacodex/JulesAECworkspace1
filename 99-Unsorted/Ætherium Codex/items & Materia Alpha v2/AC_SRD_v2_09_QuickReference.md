## 1. CRAFTING TN CALCULATOR

**Crafting TN = 10 + Conditions Modifier + Tolerance Modifier − Schematic Reduction**

| Active Conditions | Modifier |
|---|---|
| 1-2 | +2 |
| 3-4 | +4 |
| 5-6 | +6 |
| 7+ | +8 |

| Tolerance | Modifier |
|---|---|
| Wide | +0 |
| Moderate | +2 |
| Narrow | +4 |
| Razor | +6 |

| Schematic Authority | Reduction |
|---|---|
| Practitioner | −2 |
| Guild Standard | −4 |
| Institutional | −6 |
| Archival | −8 |

**Artifice Check = d20 + (Artifice Rank × 2) + Relevant Attribute + Modifiers**

**Weekly Progress = (Artifice Rank × 10) + (Relevant Attribute × 5)**

### Pool Formula

**Pool Size = (½ Effect Tier) + (½ Isotope Tier) + Overall Mastery + Integrity**

Construction Pool buys geometry. Complexity Pool buys Additives.

### ÆP

**ÆP_max = (Dominion + Tₘ) × Mastery**
**Base ÆP Cost = (ESL × 2) − 1**
**ESL = min(Effect Tier, Isotope Tier)**

Architect surcharge reduction: −⌊Intellect ÷ 2⌋ per Metamagic (min +1)
Improviser base reduction: −max(0, Anima − 3) (floor 0)

|---|---|---|

| Enhancement | No (highest) | Magical amplification |

## 8. MUTATION DEBT THRESHOLDS

**Adaptation Pressure = Source Formation Stage × 2 × Interaction Modifier**
**Adaptation Threshold = Integrity × 5** (Strain per isotope)

| Zone | Debt Range | Consequences |
|---|---|---|
| **Safe** | ≤ Lifetime XP × 2 | Benefits only. Clean adaptation. |
| **Stressed** | > ×2, ≤ ×8 | Detriments manifest alongside benefits. |
| **Overwhelmed** | > ×8 | Catastrophic. Identity coherence failing. |

**Auto-Repayment:** 25% of all XP gained applied to debt when above ×2 threshold. Minimum floor guaranteed.
**Calcification:** Debt fully cleared = permanent baseline. Settled Heritage.
**Detriments:** Cost same as positive side. Buying off eliminates them (unlike positive side which stays).

## 9. EML CALCULATOR

**EML = Highest Active Expression + floor((Total Active Expressions − 1) ÷ 4)**

Active Expressions = internal rotes + attachment rotes.
Insets, batteries, and Forge Links are NOT active expressions.

| Active Expressions | Highest CML | EML |
|---|---|---|
| 1 (CML 3) | 3 | 3 + 0 = **3** |
| 3 (CML 4, 3, 2) | 4 | 4 + 0 = **4** |
| 5 (CML 5, 4, 4, 3, 2) | 5 | 5 + 1 = **6** |
| 9 (CML 6, all others lower) | 6 | 6 + 2 = **8** |

**Material Tier caps EML.** Tier 6 housing cannot exceed EML 6.

**Forge CML = Formation Stage + (antithetical pairs mediated) − (1 if Calibrated primary)**
