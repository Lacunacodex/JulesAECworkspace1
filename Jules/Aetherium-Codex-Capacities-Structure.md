# Ætherium Codex — Capacities Structure Dump

> **Provenance:** Transcribed from 50 mobile screenshots of the Capacities database "Ætherium Codex" (captured 2026-06-26).
> **Transcription policy:** Names reproduced as displayed, preserving special characters (∞, æ, í, û). A small set of clear typos and casing errors has been corrected — see the *Corrections Applied* changelog at the end; the Capacities app remains the source of truth.
> **Truncation note:** In the object-type **schema** sections, the app UI clipped many property names mid-word (e.g. "Carrie", "Goverr", "Operationa"). Obvious expansions are written as `Carrie[r]`; genuinely ambiguous ones are marked `[?]`.
